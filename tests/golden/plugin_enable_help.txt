Handle: plugin
Verb: enable
Definition: Marks an installed plugin as enabled in the user or system state
  file.

Usage:
  resh plugin://<plugin-id>.enable [scope=user|system]
    [force=true|false] [reason=<text>] [dry_run=true|false]

Example:
  resh --json-pretty plugin://aws.enable dry_run=true

Example Output:
