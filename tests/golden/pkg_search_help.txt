Handle: pkg
Verb: search
Definition: Searches the package index by name or description and returns
  paginated matches with versions and installed state.

Usage:
  resh pkg://<alias>.search input=<json>
    <json> keys: manager, query (both required), search_in
    (name|description|all), exact, case_sensitive, limit (default 50),
    offset, include_installed, include_versions, include_repo,
    timeout_ms (default 5000), extra_args, env

Example:
  resh pkg://system.search 'input={"manager":"apt","query":"nginx","limit":1}'

Example Output:
