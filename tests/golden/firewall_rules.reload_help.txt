Handle: firewall
Verb: rules.reload
Definition: Reloads rules through the backend's own reload command for ufw or
  firewalld, or applies the saved rules file given by path.

Usage:
  resh firewall://.rules.reload [path=<file>]
    [backend=auto|iptables|nftables|ufw|firewalld]
    [family=any|ipv4|ipv6]
    [source_format=auto|backend_native|normalized_json]
    [dry_run=true|false] [validate_only=true|false]
    [backup_before_apply=true|false] [timeout_ms=<ms>]
    [format_output=json|text]

Example:
  resh --json-pretty firewall://.rules.reload backend=ufw dry_run=true

Example Output:

  --check-config.
