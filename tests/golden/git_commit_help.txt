Handle: git
Verb: commit
Definition: Creates a commit from the staged changes, first staging tracked
  changes when all=true and the listed paths when paths is given.

Usage:
  resh git://<alias>.commit path=<repo-dir> message=<text>
    [all=true|false] [paths=<p1,p2,...>] [allow_empty=true|false]
    [amend=true|false] [no_edit=true|false] [signoff=true|false]
    [author_name=<name>] [author_email=<email>]
    [committer_name=<name>] [committer_email=<email>]
    [timestamp=<iso8601|unix-seconds>] [timeout_ms=<ms>]

Example:
  resh --json-pretty git://main.commit path=/srv/app 'message=Fix typo'

Example Output:
  {
    "action": "commit",

    "backend": "git",
