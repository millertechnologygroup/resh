Handle: dns
Verb: trace
Definition: Walks the delegation from the root servers (or root_servers) to the
  name, following referrals, and reports every server asked.

Usage:
  resh dns://.trace name=<name> [rtype=<type>] [root_servers=<ip,...>]
    [prefer_ipv6=true|false] [port=<n>] [use_tcp=true|false]
    [timeout_ms=<ms>] [retries=<n>] [dnssec=true|false] [max_depth=<n>]
    [follow_cname=true|false] [include_additional=true|false]
    [want_raw=true|false] [format=json|text]

Example:
  resh dns://.trace name=www.example.com rtype=A
