Handle: pkg
Verb: remove
Definition: Removes packages, optionally purging configuration and removing
  unused dependencies.

Usage:
  resh pkg://<alias>.remove input=<json>
    <json> keys: manager, packages (both required), purge, recursive,
    assume_yes, only_if_installed, fail_if_missing, dry_run,
    timeout_ms (default 600000), arch, extra_args, env
    Each package is {name, version}; a package with source is refused
    purge: apt, apk, pacman; version and arch: apt, dnf, yum

Example:
  resh pkg://system.remove 'input={"manager":"apt","packages":[{"name":"jq"}]}'
