Handle: git
Verb: status_summary
Definition: Summarizes repository state as file counts, a sync state, and a
  recommended next action.

Usage:
  resh git://<alias>.status_summary path=<repo-dir> [remote=<name>]
    [branch=<name>] [include_untracked=true|false]
    [include_ignored=true|false] [include_remote=true|false]
    [compute_diffstats=true|false] [max_files=<n>] [timeout_ms=<ms>]

Example:
  resh --json-pretty git://main.status_summary path=/srv/app
