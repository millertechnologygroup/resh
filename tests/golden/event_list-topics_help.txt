Handle: event
Verb: list-topics
Definition: Lists the topics in the event store with their event counts and
  newest event time, and optionally the payload fields of the latest event, as a
  JSON object.

Usage:
  resh event://.list-topics [prefix=<text>] [match=<text>]
    [sources=event] [limit=<n>] [include_hidden=true|false]
    [include_stats=true|false] [include_schema=true|false]
    [format=json|text] [timeout_ms=<n>]

Example:
  resh --json-pretty event://.list-topics prefix=jobs. include_stats=true
