Handle: ssh
Verb: test
Definition: Checks through the system ssh client that the host is reachable
  (connect), that the login works (auth), that exec_command exits with 0 (exec),
  that the SFTP subsystem answers (sftp), and that the host key is known and
  matches (hostkey).

Usage:
  resh ssh://user@host[:port].test
    [tests=connect,auth,exec,sftp,hostkey] [exec_command=<cmd>]
    [handshake_timeout_ms=<ms>] [auth_timeout_ms=<ms>]
    [sftp_timeout_ms=<ms>] [exec_timeout_ms=<ms>]
    [overall_timeout_ms=<ms>] [allow_insecure_hostkey=true|false]
    [host=<host>] [port=<n>] [username=<name>]
    [auth_method=auto|key|agent|password] [password=<pw>]
    [identity_path=<file>] [identity_data=<key>] [identity_passphrase=<pp>]
    [agent_socket=<path>] [known_hosts_mode=strict|accept-new|insecure]
    [known_hosts_path=<file>] [connect_timeout_ms=<ms>] [timeout_ms=<ms>]
    [dry_run=true|false] [format=json|text]

Example:
  resh --json-pretty ssh://alice@192.0.2.10.test

  Shown with --json-pretty. The default tests are connect and auth. Each check
  opens its own ssh connection; auth is skipped when a requested connect check
  failed, and exec and sftp when a requested auth check failed. Exit status 1
  means a check failed, 124 that overall_timeout_ms (default 15000) passed.
