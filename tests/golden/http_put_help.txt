Handle: http
Verb: put
Definition: Sends a PUT request with an inline or file body and prints the
  response body as text, raw bytes, or a JSON envelope.

Usage:
  resh http://<host>/<path>.put [body=<data> | body_file=<path>]
    [content_type=<type>] [accept=text|json|bytes] [query=<k=v&...>]
    [headers=<Name:value;...>] [timeout_ms=<ms>]
    [follow_redirects=true|false] [allow_insecure=true|false]
    [ca_file=<pem>]

Example:
  resh http://api.example.com/v1/users/42.put body='{"name":"alice"}'

Example Output:
  {"id":42,"name":"alice"}

  Shown for the default accept=text, which prints the response body.
