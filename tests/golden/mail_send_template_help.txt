Handle: mail
Verb: send_template
Definition: Renders a built-in template (welcome or password_reset) with vars
  and sends it the same way as send, or only previews it when dry_run=true.

Usage:
  resh mail://send_template template=welcome|password_reset
    to=<addr,...> [vars=<json-object>] [locale=<code>]
    [strict_vars=true|false] [dry_run=true|false] [cc=<addr,...>]
    [bcc=<addr,...>] [from=<addr>] [reply_to=<addr>]
    [attachments=<json-array>] [headers=<json-object>]
    [smtp_host=<host>] [smtp_port=<n>] [use_tls=none|starttls|tls]
    [smtp_username=<user>] [smtp_password=<pass>]
    [tls_accept_invalid_certs=true|false] [timeout_ms=<ms>]
    [max_retry=<n>] [retry_backoff_ms=<ms>] [format_output=json|text]

Example:
  resh mail://send_template template=welcome to=bob@example.com dry_run=true

Example Output:
  {
    "error": null,
    "ok": true,
    "query": {
      "dry_run": true,
      "locale": null,
      "strict_vars": false,
      "template": "welcome",
      "to": [
        "bob@example.com"
      ]
    },
    "rendered": {
      "html_body": "<p>Hi <strong></strong>,</p><p>Welcome to .</p>",
      "subject": "Welcome to , !",
      "text_body": "Hi ,\n\nWelcome to .\n"
    },
    "send_result": null,
    "timestamp_unix_ms": 1792141964512,
    "warnings": [
      "Dry run: email was not sent."
    ]
  }

  Variables missing from vars render as empty strings unless strict_vars=true;
  fill them with 'vars={"user_name":"Bob","app_name":"Acme"}'. mail prints
  sorted, indented JSON without --json-pretty.
