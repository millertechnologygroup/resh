Handle: backup
Verb: restore
Definition: Restores a snapshot into a destination directory with the selected
  backend, optionally only the paths matching include patterns.

Usage:
  resh backup://<profile>.restore snapshot_id=<id> dest=<path>
    [backend=auto|restic|borg|rsync|tar] [repo_url=<repo>]
    [password=<secret>|password_file=<path>] [include=<pattern>,...]
    [exclude=<pattern>;...] [dry_run=true|false]
    [progress=true|false] [timeout_ms=<ms>] [json_pretty=true|false]
    dry_run: lists what would be restored, writes nothing.
    progress: restic and borg. timeout_ms default 1800000

Example:
  resh backup://db.restore repo_url=/srv/r snapshot_id=4f2a9c1e dest=restore
