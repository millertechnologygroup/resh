Handle: plugin
Verb: install
Definition: Resolves a plugin from a registry, URL, or local file, then
  downloads, verifies, and activates it in the local plugin store, or only
  reports the plan when dry_run is true.

Usage:
  resh plugin://<plugin-id>.install [source=registry|url|file]
    [registry=<https-url>] [url=<https-url>] [path=<file>]
    [version=<version>] [verify=sha256|none] [force=true|false]
    [allow_downgrade=true|false] [dry_run=true|false]
    [timeout_ms=<ms>] [ca_file=<pem>]

Example:
  resh plugin://aws.install source=file path=./aws-plugin dry_run=true
