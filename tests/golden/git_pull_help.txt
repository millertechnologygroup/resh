Handle: git
Verb: pull
Definition: Fetches from a remote and fast-forwards the local branch, returning
  an error when a merge or rebase would be needed, which is not implemented.

Usage:
  resh git://<alias>.pull path=<repo-dir> [remote=<name>]
    [branch=<name>] [ff_only=true|false] [prune=true|false]
    [ssh_key=<file>] [known_hosts_path=<file>] [username=<user>]
    [password=<pass>] [token=<token>] [timeout_ms=<ms>]

Example:
  resh --json-pretty git://main.pull path=/srv/app remote=origin

Example Output:
  {
    "ahead_by": 0,
    "alias": "main",
    "backend": "git",
    "behind_by": 3,
    "branch": "main",
    "commits_fetched": 3,
    "ff_only": false,
    "path": "/srv/app",
    "rebase": false,
    "remote": "origin",
    "status": "updated"
  }

  Shown for a fast-forward pull with --json-pretty. An up-to-date branch
  reports status up_to_date.
