Handle: git
Verb: pull
Definition: Fetches from a remote and fast-forwards the local branch, or
  integrates diverged history with a merge commit (or a rebase with
  rebase=true), restoring the repository on conflicts.

Usage:
  resh git://<alias>.pull path=<repo-dir> [remote=<name>]
    [branch=<name>] [ff_only=true|false] [rebase=true|false]
    [abort_on_conflict=true|false] [author_name=<name>]
    [author_email=<email>] [prune=true|false]
    [ssh_key=<file>] [known_hosts_path=<file>] [username=<user>]
    [password=<pass>] [token=<token>] [timeout_ms=<ms>]

Example:
  resh --json-pretty git://main.pull path=/srv/app remote=origin

Example Output:
  {
    "ahead_by": 0,
    "alias": "main",
    "backend": "git",
    "behind_by": 3,
    "branch": "main",
    "commits_fetched": 3,
    "ff_only": false,
    "path": "/srv/app",
    "rebase": false,
    "remote": "origin",
    "status": "updated"
  }

  Shown for a fast-forward pull with --json-pretty. An up-to-date branch
  reports status up_to_date; diverged history reports merged or rebased
  and the new commit.
