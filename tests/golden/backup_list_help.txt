Handle: backup
Verb: list
Definition: Lists the snapshots in a repository by running the backend's listing
  command, such as restic snapshots or borg list, or by reading a tar or rsync
  repository directory.

Usage:
  resh backup://<profile>.list
    [backend=auto|restic|borg|rsync|tar] [repo_url=<repo>]
    [password=<secret>|password_file=<path>] [tag=<tag>;...]
    [timeout_ms=<ms>] [json_pretty=true|false]
    tag: restic only. timeout_ms default 10000

Example:
  resh --json-pretty backup://db.list backend=restic repo_url=/srv/restic
