Handle: file
Verb: replace
Definition: Replaces literal text or regular expression matches in a file,
  rewriting it atomically, and reports the replacement count as a JSON object.

Usage:
  resh file://<path>.replace pattern=<text> replacement=<text>
    [regex=true|false] [count=<n>] [dry_run=true|false]
    [backup=<suffix>]

Example:
  resh --json-pretty file:///etc/app.conf.replace pattern=8080 replacement=9090

Example Output:
  {
    "changed": true,
    "count_limit": null,
    "dry_run": false,
    "new_bytes": 412,
    "original_bytes": 412,
    "path": "/etc/app.conf",
    "pattern": "8080",
    "regex": false,
    "replacements": 2
  }

  Shown with --json-pretty.
