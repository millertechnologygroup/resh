Handle: system
Verb: memory
Definition: Reports RAM, swap, hugepage, and cgroup memory usage in bytes, with
  each section and the human-readable summaries selectable by option.

Usage:
  resh system://.memory [include_swap=true|false]
    [include_cgroup=true|false] [include_hugepages=true|false]
    [include_human=true|false] [include_raw=true|false]
    [include_paths=true|false] [format=json|text] [input=<json>]
    defaults: include_swap, include_cgroup, include_hugepages and
      include_human true; include_raw and include_paths false;
      format=json

Example:
  resh --json-pretty system://.memory include_hugepages=false
