Handle: fs
Verb: fsck
Definition: Alias for check.

Usage:
  resh fs://<alias>.fsck target=<dir-or-device>
    [by=auto|mountpoint|device] [filesystem_type=<fstype>]
    [mode=check|repair|auto] [allow_repair=true|false]
    [aggressiveness=safe|normal|aggressive] [force=true|false]
    [allow_online_check=true|false]
    [require_unmounted_for_repair=true|false]
    [skip_if_mounted=true|false] [btrfs_use_scrub=true|false]
    [btrfs_allow_offline_check=true|false] [dry_run=true|false]
    [timeout_ms=<ms>]

Example:
  resh --json-pretty fs://local.fsck target=/srv/disk.img

  Shown for an unmounted ext4 image file with --json-pretty. The verb field
  is "check" for both spellings. Supported types: ext2, ext3, ext4, vfat,
  xfs, btrfs; others (such as reiserfs) are refused with exit 1.
  mode=repair (needs allow_repair=true) runs fsck -p (-y with
  aggressiveness=aggressive), fsck.vfat -a, xfs_repair or btrfs check
  --repair on an unmounted filesystem; a mounted btrfs is scrubbed. Errors
  found are reported in analysis with exit 0; a tool that fails to run its
  check exits 1. Defaults: by=auto, mode=check, aggressiveness=safe,
  allow_repair=false, allow_online_check=true,
  require_unmounted_for_repair=true, btrfs_use_scrub=true,
  timeout_ms=600000.
