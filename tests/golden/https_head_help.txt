Handle: https
Verb: head
Definition: Sends a HEAD request and reports the status and response headers as
  JSON.

Usage:
  resh https://<host>/<path>.head [accept=json|text|bytes]
    [query=<k=v&...>] [headers=<Name:value;...>] [timeout_ms=<ms>]
    [follow_redirects=true|false] [allow_insecure=true|false]

Example:
  resh https://example.com/index.html.head

Example Output:
  {
    "headers": {
      "content-length": "1256",
      "content-type": "text/html; charset=UTF-8",
      "last-modified": "Mon, 13 Jan 2025 20:11:20 GMT"
    },
    "ok": true,
    "reason": "OK",
    "status": 200,
    "url": "https://example.com/index.html"
  }

  Shown with --json-pretty.
