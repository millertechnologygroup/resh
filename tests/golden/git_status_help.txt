Handle: git
Verb: status
Definition: Reports the current branch and upstream, the staged, unstaged,
  untracked, and conflicted files, and any operation in progress.

Usage:
  resh git://<alias>.status path=<repo-dir>
    [include_untracked=true|false] [include_ignored=true|false]
    [include_staged=true|false] [include_branch=true|false]
    [include_remote=true|false] [timeout_ms=<ms>]

Example:
  resh --json-pretty git://main.status path=/srv/app
