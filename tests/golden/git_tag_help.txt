Handle: git
Verb: tag
Definition: Lists, creates, or deletes tags, listing all tags sorted by name
  when no action is given.

Usage:
  resh git://<alias>.tag path=<repo-dir> [action=list|create|delete]
    [name=<tag>] [names=<t1,t2,...>] [pattern=<glob>]
    [sort=name|version|taggerdate|committerdate]
    [annotated=true|false] [message=<text>] [target=<rev>]
    [force=true|false] [author_name=<name>] [author_email=<email>]
    [timestamp=<iso8601|unix-seconds>] [timeout_ms=<ms>]

Example:
  resh --json-pretty git://main.tag path=/srv/app
