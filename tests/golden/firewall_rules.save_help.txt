Handle: firewall
Verb: rules.save
Definition: Saves a snapshot of the current rules to the file given by path, as
  normalized JSON, backend-native data, or both.

Usage:
  resh firewall://.rules.save path=<file>
    [backend=auto|iptables|nftables|ufw|firewalld]
    [family=any|ipv4|ipv6] [include_all_backends=true|false]
    [format=normalized_json|backend_native|both] [compress=none|gzip]
    [include_metadata=true|false] [dry_run=true|false]
    [overwrite=true|false] [create_dirs=true|false] [timeout_ms=<ms>]
    [format_output=json|text]

Example:
  resh --json-pretty firewall://.rules.save path=/var/backups/firewall.json
