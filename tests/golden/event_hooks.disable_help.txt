Handle: event
Verb: hooks.disable
Definition: Disables one of the built-in hooks fs, log, or mq for this and every
  later emit of the user, recording it in the event store.

Usage:
  resh event://.hooks.disable name=fs|log|mq

Example:
  resh event://.hooks.disable name=mq

Example Output:
  {"changed":true,"disabled":true,"hook":"mq"}

  changed is false if the hook was already disabled.
