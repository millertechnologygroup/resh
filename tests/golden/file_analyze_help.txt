Handle: file
Verb: analyze
Definition: Samples a file and reports its ASCII ratio, byte entropy, line
  count, and a json, csv, log, text, or binary classification as a JSON object.

Usage:
  resh file://<path>.analyze [max_bytes=<n>]

Example:
  resh --json-pretty file:///var/log/app.log.analyze

Example Output:
  {
    "ascii_ratio": 1.0,
    "classification": "text",
    "entropy": 4.004247855285173,
    "format_hints": {
      "is_csv": false,
      "is_json": false,
      "is_log_like": false
    },
    "line_count": 4,
    "null_byte_present": false,
    "path": "/var/log/app.log",
    "sample_bytes": 48,
    "size_bytes": 48
  }

  Shown with --json-pretty.
