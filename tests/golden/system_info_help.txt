Handle: system
Verb: info
Definition: Gathers host information for selected scopes, such as os, kernel,
  cpu, memory, and load, into one report; a scope that cannot be read is marked
  available false.

Usage:
  resh system://.info [scopes=<list>] [fields=<list>]
    [sample_duration_ms=<n>] [sample_min_ms=<n>] [per_cpu=true|false]
    [max_mounts=<n>] [max_process_classes=<n>] [include_raw=true|false]
    [include_paths=true|false] [timeout_ms=<n>] [format=json|text]
    [input=<json>]
    scopes: os, kernel, cpu, memory, load, disk, process, pressure,
      cgroup, virtualization (default os,kernel,cpu,memory,load)
    fields: <scope> or <scope>.<key> entries; only these are reported
    defaults: sample_duration_ms=0 (no CPU sampling; per_cpu needs it),
      sample_min_ms=50, per_cpu=false, max_mounts=32,
      max_process_classes=5, include_raw=false, include_paths=false,
      timeout_ms=30000, format=json

Example:
  resh --json-pretty system://.info scopes=kernel,load
