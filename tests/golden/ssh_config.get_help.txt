Handle: ssh
Verb: config.get
Definition: Parses the local OpenSSH client config files and reports the
  settings that apply to a host (the URL host or host=), using OpenSSH's
  first-match rules.

Usage:
  resh ssh://<host>.config.get [host=<name>] [user_config_path=<path>]
    [system_config_path=<path>] [extra_config_paths=<path,...>]
    [follow_includes=true|false] [include_raw_entries=true|false]
    [include_origin=true|false] [user_home=<dir>]
    [max_config_bytes=<n>] [max_includes=<n>] [max_hosts=<n>]
    [dry_run=true|false] [format=json|text]

Example:
  resh ssh://web01.config.get user_config_path=cfg system_config_path=/dev/null

Example Output:

  Printed as indented JSON in field order for a file cfg holding HostName and
  User under Host web01 (/dev/null stands in for an empty system config). The
  first value obtained for an option wins, as in ssh; include_raw_entries=false
  drops raw_entries.
