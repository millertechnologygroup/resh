Handle: dns
Verb: lookup
Definition: Queries one DNS record type for a name and prints the answer,
  authority and additional records as JSON or text.

Usage:
  resh dns://.lookup name=<name> [rtype=<type>] [servers=<ip,...>]
    [port=<n>] [use_tcp=true|false] [timeout_ms=<ms>] [retries=<n>]
    [dnssec=true|false] [follow_cname=true|false]
    [include_authority=true|false] [include_additional=true|false]
    [randomize_servers=true|false] [format=json|text]

Example:
  resh dns://.lookup name=example.com rtype=MX
