Handle: proc
Verb: nice.inc
Definition: Raises the nice value of every thread of a process by a delta,
  lowering its priority.

Usage:
  resh proc://<pid>.nice.inc delta=<0..39>

Example:
  resh --json-pretty proc://1234.nice.inc delta=5

Example Output:
  {
    "changed": true,
    "delta": 5,
    "nice_after": 5,
    "nice_before": 0,
    "pid": 1234,
    "threads": [
      {
        "changed": true,
        "nice_after": 5,
        "nice_before": 0,
        "status": "ok",
        "tid": 1234
      }
    ]
  }

  Shown with --json-pretty. Each thread moves from its own value; if any
  would leave -20..19, the call is refused and nothing is changed.
