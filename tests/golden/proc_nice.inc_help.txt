Handle: proc
Verb: nice.inc
Definition: Raises the nice value of a process by a delta, lowering its
  priority.

Usage:
  resh proc://<pid|self>.nice.inc delta=<0..39>

Example:
  resh --json-pretty proc://1234.nice.inc delta=5

Example Output:
  {
    "changed": true,
    "delta": 5,
    "nice_after": 5,
    "nice_before": 0,
    "pid": 1234
  }

  Shown with --json-pretty. A result outside -20..19 is refused and
  nothing is changed.
